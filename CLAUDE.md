# Wisdom — project context

Personal collection of AA/recovery quotes plus poems and prayers (~934 cards),
tagged for search, as a static site on GitHub Pages (`main`, root) →
https://lanehaden157.github.io/Wisdom
The owner is in recovery — treat it as a personal, meaningful archive.

The modular refactor is **built** (was one `index.html`). History in
[refactor_plan.md](refactor_plan.md); per-session notes in
[session_index.md](session_index.md) — read first.

## Run it

- Just open `index.html` — data and code load as plain `<script>` tags, so
  `file://` works. No build, no server, no dependencies (Google Fonts via CDN).
- Local server only if you prefer: `python -m http.server` in this folder.
- Rebuild the base corpus after editing anything in `source/`:
  `python scripts/build_data.py` then `python scripts/validate.py`.

## Data model as built

- **Base corpus** = the frozen v1 corpus (owner prefers its wording). `build_data.py`
  turns it into `data/quotes.js`, assigns each card a `category`, appends
  `new-quotes.json`, and folds in the poems/prayers file.
- **Category** (quote / poem / prayer) is a field in `quotes.js`, pipeline-assigned.
  Poems/prayers come from `source/poems-prayers-raw.txt`; where an item there
  matched a corpus quote (similarity ≥ 0.86) that card keeps its id, takes the
  poems-file text, and leaves the Quotes tab. This session: 14 matched+moved,
  11 new P&P items, 2 new quotes → 909 quote / 10 poem / 15 prayer.
- **Tags**: clean slate — `tags.js` / `assignments.js` start empty. The old
  67-tag taxonomy is in `data/archive/quotes-v1.json` only, unused. Rebuild by
  hand via the tagging queue; free-text tag creation is intentional now.
- **Origin** (aa / religious / misc): one manual value per card, `origins.js`,
  no seed. Renders as a coloured left edge (`--origin-*` tokens).
- **quote-edits.js** mirrors the old edits/deletes/drafts model as a file:
  app-created cards get ids ≥ 100000.

## Non-negotiable invariants

- `build_data.py` writes `data/quotes.js` (+ `source/ids.json`) and nothing
  else. It must never touch tags / assignments / origins / quote-edits — that
  would erase the manual tagging work.
- `validate.py` fails on: duplicate id; category not quote/poem/prayer;
  assignment or origin referencing a dead id; bad origin value; the owner's
  name or an explicit date pattern in `quotes.js`. Run before every publish.
- Quote ids are stable forever (`ids.json` hash→id). No id-renumbering step.

## Save / conflict model

Save PUTs each app-written data file individually (small payloads) via the
GitHub Contents API, after checking `data/stamp.js` hasn't advanced since load
(→ "site changed since you loaded (phone?)"). Then it bumps the stamp and
clears localStorage. No more whole-DOM serialization, so the old token-scrub
hack is gone. PAT: fine-grained, this repo only, Contents r/w, set via ⚙,
stored in localStorage `wisdom_site_config_v1`, never written to a served file.

## localStorage

Every mutation writes the full working object to
`wisdom_v2::<stamp>::{tags|assign|origins|qedits}`. Namespacing by the publish
stamp means a stale cached page finds nothing under the new stamp and starts
clean from the published data.

## Style intent

"Card catalog": cream paper, oxblood `--accent`, ruled index-card detailing.
Fraunces (serif, quotes) + Inter (UI) + IBM Plex Mono (tags/ids). Phone-first —
sticky bar, single column narrow, bottom-sheet modals. Poems/prayers render in a
2-up "reading" grid with line breaks kept; prayers centre. Origin colours sit
inside the palette (pine / oxblood / brass), never fight it.
