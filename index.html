Site connection

Lets the Save button write changes straight back to your GitHub site. The token is stored only in this browser on this device — it is never put into the site file, so people you share the link with can read but never change anything.

Make one at github.com → Settings → Developer settings → Personal access tokens → Fine-grained. Scope it to ONLY this repository, permission Contents: read and write, nothing else. If it ever expires or leaks, delete it there and paste a new one here.
